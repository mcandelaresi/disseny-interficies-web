# Riftpedia

Riftpedia és una web educativa sobre League of Legends on es poden consultar els campions, les runes, els aspectes i els objectes del joc.

## Tecnologies

- HTML5
- CSS3

## Accessibilitat

- HTML semàntic.
- Navegació amb teclat i focus visible.
- Text alternatiu a les imatges informatives.
- Formularis amb etiquetes i validació HTML5.
- Contrast de colors i disseny adaptable.

## Funcionament

Obre el fitxer `index.html` al navegador. Els formularis són de demostració i no disposen de base de dades.
